# Design Assets

Brand guidelines, logos, and visual identity systems for dataimago, following Barbara Kruger-inspired critical design principles.

## Directory Structure

```
Design_Assets/
├── branding_guide.md           # Complete brand guidelines and design philosophy
└── logos/
    └── dataimago_supreme.svg    # Primary logo inspired by Barbara Kruger
```

## Overview

Dataimago's design assets embody our commitment to critical design practice—using visual communication as a tool for consciousness-raising rather than mere corporate branding.

### Design Philosophy
- **Barbara Kruger influence**: Bold typography and critical messaging
- **Accessible yet futuristic**: Professional credibility with forward-thinking aesthetics
- **Critical consciousness**: Design that questions rather than reinforces power structures

### Key Assets
- **branding_guide.md**: Comprehensive brand guidelines including color palette, typography system, and design principles
- **dataimago_supreme.svg**: Primary logo combining critical design with professional presentation
