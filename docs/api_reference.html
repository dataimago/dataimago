Generate Quarto Documentation from R Package

Description

This function embodies dataimago’s principle of embedding AI within culture for emancipatory purposes.

Converts R package documentation (.Rd files) and metadata (DESCRIPTION) into Quarto-compatible .qmd files for website generation. Integrates dataimago branding and philosophical foundations.

Usage

create_quarto_documentation(
  package_path = ".",
  output_path = "quarto_website",
  include_description = TRUE,
  include_foundation_links = TRUE,
  template = "dataimago"
)

Arguments

  • package_path: Character. Path to the R package root directory (default: “.”)
  • output_path: Character. Path to quarto website directory (default: “quarto_website”)
  • include_description: Logical. Include DESCRIPTION file in output (default: TRUE)
  • include_foundation_links: Logical. Add links to dataimago foundations (default: TRUE)
  • template: Character. Documentation template to use (default: “dataimago”)

Details

This function performs the following operations:

  • Parses the package DESCRIPTION file for metadata
  • Converts all .Rd files in man/ to Quarto markdown format using Rd2md
  • Generates a comprehensive api_reference.qmd file
  • Updates dataimago design assets and branding
  • Integrates philosophical foundation context where appropriate

The generated documentation maintains the dataimago ethical framework while providing comprehensive package reference material suitable for AI-assisted development and human consumption.

Value

Invisible. Creates/updates .qmd files in the quarto_website directory

Examples

Examples using dataimago’s ethical AI framework:

# Generate documentation for current package
create_quarto_documentation()

# Generate for specific package with custom output
create_quarto_documentation(
  package_path = "/path/to/my/package",
  output_path = "docs/website"
)

This function is part of the dataimago ethical AI framework.
