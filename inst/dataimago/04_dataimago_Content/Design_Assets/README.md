## Overview

Dataimago's design assets embody our commitment to critical design practice—using visual communication as a tool for consciousness-raising rather than mere corporate branding.

### Design Philosophy
- **Barbara Kruger influence**: Bold typography and critical messaging
- **Accessible yet futuristic**: Professional credibility with forward-thinking aesthetics
- **Critical consciousness**: Design that questions rather than reinforces power structures

### Key Assets
- **branding_guide.md**: Comprehensive brand guidelines including color palette, typography system, and design principles
- **AI Monogram Series**: Superimposed 'a' and 'i' letters creating unified symbol using Futura italic
- **Dataimago Wordmark Series**: Full company name with integrated 'ai' character overlap
- **Background Variants**: Logo versions optimized for different contexts and applications

### Logo System Philosophy
The dataimago logo system embodies our core philosophical principle through its **typographic synthesis**:
- The **superimposed 'a' and 'i'** represents the fusion of **human agency** ('a') and **artificial intelligence** ('i')
- **Futura italic** provides the geometric precision needed for seamless character overlap
- The result creates a **new unified symbol** that is neither purely human nor purely artificial, but genuinely collaborative
