# Visual Framework Assets

This directory contains visual diagrams and frameworks that translate dataimago's complex philosophical and technical concepts into accessible, compelling visualizations for diverse audiences.

## Core Visual Frameworks

- **sgpflow_stack.svg** - Technical architecture diagram showing the AI system layers and multi-level interfaces
- **flow_based_society.svg** - Societal transformation visualization contrasting disciplinary vs. flow-based systems
- **ethical_governance_model.svg** - Democratic AI governance framework with stakeholder participation
- **core_concept_metaphors.svg** - Visual metaphors for key philosophical concepts (synthesis, dialectics, flow, etc.)
- **frankfurt_school_ai_framework.svg** - Application of Frankfurt School critical theory to contemporary AI development

## Design Philosophy

Our visual frameworks follow principles derived from critical theory and accessible design:

### Critical Visual Literacy
- Question power relations embedded in visual conventions
- Use design as critical practice, not just illustration
- Make philosophical concepts visceral and immediate
- Challenge rather than reinforce dominant tech industry aesthetics

### Multi-Audience Accessibility
- **Academic rigor** without exclusionary complexity
- **Technical precision** with conceptual clarity
- **Professional credibility** across policy and business contexts
- **Public accessibility** without oversimplification

### Emancipatory Visualization
- Show human agency rather than technological determinism
- Emphasize democratic participation and transparency
- Visualize transformation and growth rather than static control
- Center marginalized voices and diverse perspectives

## Visual Elements System

### Color Palette
- **Red (#CC4125)**: Critical consciousness, revolutionary energy
- **Blue (#2E86AB)**: Democratic participation, analytical thinking
- **Purple (#A23B72)**: Synthesis, hermeneutic understanding
- **Orange (#F18F01)**: Transformation, human agency
- **Green (#4CAF50)**: Growth, emancipation, flourishing

### Typography
- **Futura Italic Bold**: Primary titles and key concepts
- **Supporting fonts**: Clear hierarchy for different content types

### Visual Metaphors
- **Circles**: Human elements and organic processes
- **Networks**: Democratic participation and distributed agency
- **Flow lines**: Dynamic change and growth trajectories
- **Bridges**: AI as enhancement rather than replacement

## Usage Guidelines

### For Presentations
- Use high-resolution SVG files for scalability
- Consider audience background and adjust complexity accordingly
- Combine multiple frameworks to build comprehensive arguments
- Allow time for audience to process visual information

### For Publications
- Include detailed captions explaining visual elements
- Reference philosophical foundations and theoretical sources
- Adapt color schemes for print accessibility if needed
- Provide alternative text descriptions for accessibility

### For Digital Applications
- Ensure responsive design across different screen sizes
- Consider interactive elements for web-based presentations
- Maintain visual consistency with overall brand guidelines
- Test accessibility with screen readers and assistive technologies
